# AI Demand Forecasting

Conversion-focused SaaS site for `aidemandforecasting.space`, built with Vite, React, Cloudflare Workers Assets, Cloudflare Pages, KV analytics, and Creem hosted checkout.

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run test
npm run cloudflare:deploy
npm run pages:deploy
```

Production secrets are configured outside the repository. Do not commit payment, registrar, search, GitHub, or Cloudflare credentials.
